# AROUND Trips v1.7

Trips sind die Planungsstufe nach Collections.

- `/my-around/planen` — persönlicher Planungs-Hub
- `/my-around/collections` — sammeln und ordnen
- `/my-around/trips` — Reisen anlegen
- `/my-around/trips/[id]` — Tagesplanung

Bestehende Supabase-Tabellen werden wiederverwendet. Keine Migration nötig.
