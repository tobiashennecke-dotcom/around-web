# AROUND — v0 / Coding Agent Implementation Brief

Build the repository exactly as a premium German-language golf media + discovery product.

Do not redesign the visual identity.

## Non-negotiable visual direction
- AROUND Anthracite #212322
- Warm White #F5F3EE
- Lime #D6EA2A
- Blue #0047BB
- Pink #F55096
- heavy clean sans + refined editorial serif
- editorial asymmetry
- generous negative space
- minimal corner radius
- no default shadows
- no SaaS dashboard aesthetic
- no golf clichés

## Product graph
Destination ↔ Place ↔ Story ↔ Person ↔ Object ↔ Collection

## Core journey
Discover → Destination → Place → Story → Save → My Around

## Requirements
- Next.js App Router
- Server Components by default
- Client Components only for interaction
- Supabase SSR auth pattern
- Sanity structured references
- guest saves before login
- account saves after login
- mobile bottom nav
- accessible keyboard/focus states
- responsive editorial type scale
- no dead-end pages
