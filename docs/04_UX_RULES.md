# AROUND UX Rules

1. Mobile ist kein kleiner Desktop.
2. Jede Seite braucht mindestens einen sinnvollen nächsten Schritt.
3. THE DROP bedeutet immer Speichern/Merken.
4. Keine Bewertung mit Sternen oder 1–10.
5. Kuratierung wird erklärt, nicht versteckt.
6. Signal-Farbe hat Bedeutung:
   - Lime = Discover / Places / Save
   - Blue = Ideas / Future / Editorial
   - Pink = People / Culture / Opinion
7. Pro Screen maximal eine dominante Signalfarbe.
8. Storyseiten enthalten `IN THIS STORY`.
9. Place-Seiten enthalten `AROUND IT`.
10. Destination-Seiten verbinden `PLAY / STAY / EAT / DO / STORIES`.
11. Search zeigt kuratierte Relevanz, nicht Vollständigkeit.
12. Save muss vor Login funktionieren; Login verbessert Persistenz, blockiert aber Discovery nicht.
